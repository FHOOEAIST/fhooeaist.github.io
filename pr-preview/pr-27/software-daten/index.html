Datensätze

  • Datensatz Python

    Visual Computing Fernerkundung & UAV

    Groß angelegter Datensatz mit 389 gepaarten RGB- und Wärmebild-Videosequenzen aus Drohnenflügen über Wäldern und Waldrändern in Österreich, jedes Bild global georeferenziert und mit Wildtier-Annotationen. Das Repository enthält Skripte zum Herunterladen, Aufbereiten und Visualisieren. Die Daten stehen unter CC-BY-4.0 (die Baum- und Totholz-Layer unter CC-BY-NC-4.0), die Skripte unter MIT.

    Lizenz
    CC-BY-4.0, CC-BY-NC-4.0, MIT
    Projekt
    Bambi
    Zitieren
    The BAMBI Dataset: Multimodal Nadir UAV-Recordings of Forest Wildlife (2026)
    Repository
