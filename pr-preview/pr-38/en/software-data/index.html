Software & Data

Software, datasets and models from our research projects – openly available for reuse. If you use them in your work, please cite the publication given.

All repositories of the research group on GitHub

Datasets

  • Dataset Python

    Visual Computing Remote Sensing & UAV

    Large-scale airborne dataset of 389 paired RGB and thermal video sequences recorded over forest and forest-adjacent habitats in Austria, every frame globally geo-referenced and annotated with wildlife. The repository provides scripts for downloading, processing and visualising the data. The data is licensed CC-BY-4.0 (the tree cover and deadwood layers CC-BY-NC-4.0), the scripts MIT.

    Licence
    CC-BY-4.0, CC-BY-NC-4.0, MIT
    Project
    Bambi
    Please cite
    The BAMBI Dataset: Multimodal Nadir UAV-Recordings of Forest Wildlife (2026)
    Repository

    Visual Computing Remote Sensing & UAV
